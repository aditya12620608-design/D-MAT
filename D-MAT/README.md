```text

├── index.html

│   ├── grammar.js
│   ├── moore-mealy.js
│   └── syllabus.js
└── README.md
```

## How to run

1. Open the `D-MAT` folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click inside the editor and choose **Open with Live Server**. You can also open `index.html` directly in a browser.

## Technologies used

- HTML for the page structure.
- CSS for the layout, colours, and responsive design.
- JavaScript for the interactive workbenches and calculations.
- Browser `localStorage` for syllabus progress and local experiment history.

No separate backend or database server is required. The project uses classic JavaScript files so the existing inline button actions continue to work.
