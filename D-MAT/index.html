D-MAT

Discrete mathematics and computation workbench

Sets, relations and functions

Separate elements with commas. Pairs are written a-b for relations and a>b for functions.

Logic and Boolean expressions

Use & | ~ ^ -> <-> (or ∧ ∨ ¬ ⊕ → ↔), parentheses, and 0/1. Every subexpression gets its own column, so you can follow the evaluation.

Finite automata simulator

One transition per line as “from, symbol, to”. Use e for ε. NFAs and ε-NFAs work too.

Try: ending with 11, starting with 01, containing 101, even number of 0s, number of 1s divisible by 3, binary number divisible by 3, exactly 2 a’s, at least 2 b’s, length divisible by 2.

Graph theory visualizer

Vertices separated by commas. Edges are one per line, as A-B or A-B:4 with a weight.

Grammar analyzer

One rule per line, alternatives split by |. Write ε as e. Write symbols with spaces, or without spaces for single characters. Capitalized names on the left are variables.

The parser searches leftmost derivations with pruning. It handles any context-free grammar and stops at 40,000 forms.

Welcome to D-MAT

Choose a workbench. Every result comes with the steps that produced it, and signed-in students can save experiments to History.

Moore and Mealy machines

Finite automata with output. A Moore machine puts the output on states, a Mealy machine puts it on transitions. Run a string, then convert the machine to the other type.
